📚 Thanvi Language Tutorial

1. Getting Started

Thanvi is a simple programming language designed for learning. Here's your first program:

show "Hello, Thanvi!" finish

2. Variables

Create variables using the set keyword:

set name = "Alice" set age = 25 set is_active = true

3. Data Types

Numbers

Integers and decimals: 42, 3.14

Strings

Text in quotes: "Hello"

Booleans

True or false values

4. Showing Output

Use show to display values:

show "Number: " + 42 show 10 + 5 show true finish

Arithmetic Operators

Addition

show 10 + 5

Subtraction

show 10 - 5

Multiplication

show 10 * 5

Division

show 10 / 5

Comparison Operators

Equal

5 == 5

Not Equal

5 != 3

Less Than

3 < 5

Greater Than

5 > 3

Greater or Equal

5 >= 5

Check / Otherwise Statements

Make decisions based on conditions:

set age = 20 check age >= 18 => show "You are an adult" otherwise => show "You are a minor" end finish

Repeat Loops

Repeat code while a condition is true:

set count = 1 repeat count <= 5 => show count set count = count + 1 end finish

Loop Output

1 2 3 4 5

Declaring Functions

Create reusable code blocks:

define add(a, b) => give a + b end show add(5, 3) finish

Multiple Parameters

define greet(first, last) => show "Hello, " + first + " " + last end greet("John", "Doe") finish

Recursive Functions

Functions can call themselves:

define factorial(n) => check n <= 1 => give 1 otherwise => give n * factorial(n - 1) end end show factorial(5) finish
